A responsive college website that gives information about the college, with a login form for students. When a user submits the form, the details are sent by email using EmailJS and a confirmation message is shown. Built using HTML, CSS, and JavaScript.

## Features
- Home page with college introduction
- About College page with details about the college
- Login form for students
- Form details are sent by email using EmailJS
- Confirmation message after submitting: "We will reach out to you soon"
- Responsive design that works on mobile, tablet, and desktop
- Easy navigation menu
- Contact section

## Tools and Technologies Used
- HTML: page structure
- CSS: styling and responsive layout
- JavaScript: form validation and interactivity
- EmailJS: sending the form details by email
- VS Code: code editor
- Git and GitHub: version control and hosting

## How I Created It
1. Planned the pages and layout of the website
2. Built the structure of each page with HTML
3. Styled the pages and made them responsive with CSS
4. Created the login form and added validation with JavaScript
5. Connected the form to EmailJS so the user's details are emailed to me
6. Added a confirmation message that appears after the form is submitted
7. Uploaded the project to GitHub

## How It Works
1. The user fills in the form with their information
2. JavaScript collects the details and sends them through EmailJS
3. The details arrive in the college email inbox
4. The user sees the message "We will reach out to you soon"

## How to Run
1. Download or clone this repository
2. Open `index.html` in your browser
